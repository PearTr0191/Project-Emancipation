# Common App Changes & Policy Watch

> Regulation-sensitive content. Verify current status before acting — policies shift cycle to cycle.

## Common App 2025 updates (confirmed in source speech, June 2025 post)

Two structural changes announced by Common App:

1. **Additional Information section: 650 → 300 words.** Half the space means ruthless prioritization — only context that changes how an AO reads the application.
2. **"Community Disruption" section renamed "Challenges and Circumstances."** Broader framing; same function of explaining disrupted schooling.

### The 4-step protocol for every item you list there
1. Say what happened, how it affected you, and what you did about it
2. Use bullet points, avoid fancy language
3. Think like an AO: what context do they need to *fairly* understand my application?
4. Do NOT paste supplemental essays or repeat anything already elsewhere in the application [DLU38sUxwF5]

## MERIT Act (watch item, July 2026)

Reintroduced in the Senate in late July 2026; would stop accrediting bodies from weighing race-related criteria (post-acceleration-of the 2023 SCOTUS affirmative-action ruling landscape). Captured from carousel DcRdrxWmLAM (2026-08-20).

Status: legislation — not law at capture time. For admissions planning this mainly affects institutional scholarship/accreditation dynamics, not directly the student-side application. Monitor before advising on anything race-conscious.
